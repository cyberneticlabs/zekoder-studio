3. External worktree workspace: registered project root shown, external checkout inaccessible.
4. Upload small binary/empty file: remote selected-folder bytes match; cancelled picker creates nothing.
5. Collision/oversized/permission error: old content unchanged, clear error.
6. Right-click safe ZIP/TAR → Extract → confirm: new sibling directory with nested files.
7. Corrupt/unsafe/oversized archive or existing destination: error, outside sentinel unchanged, no partial output or honest cleanup failure.
8. Symlink disabled; normal file explains native opening deferred.
9. Switch workspace mid-request: no stale display; mutation retains original explicit workspaceId.
10. Repeat on browser client, keyboard action equivalent and missing capability; mobile unsupported.
