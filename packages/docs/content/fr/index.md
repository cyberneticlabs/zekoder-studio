ZeKoder Desktop est l'endroit où vous lancez, surveillez et dirigez vos agents de code IA. Il se connecte aux machines qui hébergent votre code, qui reste donc là où il se trouve.

## Pour commencer

- [Installer ZeKoder Desktop](/fr/getting-started/install) sur votre ordinateur.
- [Connecter un hôte](/fr/getting-started/connect-a-host) pour travailler sur une machine distante ou un serveur.
- Consultez [Nouveautés](/fr/whats-changed) pour voir ce qui change dans cette version.

## À propos de cette documentation

Chaque version de ZeKoder publie sa propre copie de la documentation. Utilisez le sélecteur de version dans l'en-tête pour lire la documentation qui correspond à la version que vous utilisez.
