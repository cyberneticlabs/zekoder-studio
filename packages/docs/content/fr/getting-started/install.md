ZeKoder Desktop est la façon recommandée d'utiliser ZeKoder. Il démarre et gère son propre démon local : il n'y a rien d'autre à installer.

## Avant de commencer

Il vous faut au moins un agent de code pris en charge, installé et connecté sur la machine qui l'exécutera. ZeKoder fonctionne avec Claude Code, Codex, GitHub Copilot, OpenCode, Pi, Antigravity et Muse Code.

## Installer l'application de bureau

1. Téléchargez le programme d'installation pour votre système d'exploitation sur [zekoder.com](https://zekoder.com).
2. Lancez le programme d'installation, puis ouvrez ZeKoder Desktop.
3. L'application démarre automatiquement son démon local. Votre machine apparaît comme premier hôte.

## Lancer votre premier agent

1. Ouvrez un dossier de projet dans l'application.
2. Choisissez un agent de code et décrivez la tâche.
3. Suivez la progression de l'agent, répondez à ses questions et relisez le résultat.

## Mises à jour

ZeKoder Desktop recherche les mises à jour et vous prévient lorsqu'une nouvelle version est prête. Chaque version a sa propre documentation : choisissez la vôtre dans le sélecteur de version de l'en-tête.
