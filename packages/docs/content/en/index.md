ZeKoder Desktop is where you run, monitor, and direct your AI coding agents. It connects to the machines your code lives on, so your code stays where it is.

## Start here

- [Install ZeKoder Desktop](/getting-started/install) on your computer.
- [Connect a host](/getting-started/connect-a-host) to work on a remote machine or a server.
- Read [What changed](/whats-changed) to see what is new in this version.

## About these docs

Each release of ZeKoder publishes its own copy of the documentation. Use the version selector in the header to read the docs that match the version you run.
