ZeKoder Desktop is the recommended way to use ZeKoder. It starts and manages its own local daemon, so there is nothing else to install.

## Before you begin

You need at least one supported coding agent installed and signed in on the machine that will run it. ZeKoder works with Claude Code, Codex, GitHub Copilot, OpenCode, Pi, Antigravity, and Muse Code.

## Install the desktop app

1. Download the installer for your operating system from [zekoder.com](https://zekoder.com).
2. Run the installer and open ZeKoder Desktop.
3. The app starts its local daemon automatically. Your local machine appears as the first host.

## Start your first agent

1. Open a project folder in the app.
2. Choose a coding agent and describe the task.
3. Follow the agent's progress, answer its questions, and review the result.

## Updates

ZeKoder Desktop checks for updates and tells you when a new version is ready. Each version has its own documentation: pick yours in the version selector in the header.
